# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository. Do not
open a public issue for suspected vulnerabilities. Include reproduction steps,
affected versions, impact, and any suggested remediation. You can expect an
initial acknowledgement within seven days.

Rotate any credential or secret that may have been exposed before sharing logs
or configuration samples.
