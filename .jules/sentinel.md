## 2024-XX-XX - Fix XSS in JSON Stringify
**Vulnerability:** DOM-based XSS in template files (`management.html`, `profile.html`) when rendering audit detail JSON data directly to `.innerHTML` using `JSON.stringify(..., null, 2)` inside template string literals.
**Learning:** `JSON.stringify` does not escape HTML entities `<` or `>`. When its result is appended directly to `.innerHTML`, any malicious HTML injected inside the original JSON structure will be executed by the browser, leading to XSS. This is specifically relevant here because `detailsJson` contains fields like `User-Agent` which are user-controllable.
**Prevention:** For pre-formatted display of JSON data, either securely escape the string before setting `.innerHTML`, or build the HTML structure dynamically (`innerHTML = '<pre>...</pre>'`) and inject the untrusted data using the `.textContent` property (`document.querySelector('pre').textContent = ...`) which the browser natively encodes.
