## 2024-06-28 - HMGet Null Returns
**Learning:** When replacing HGetAll with HMGet in go-redis, `vals[0] == nil` is an unsafe way to check if a hash exists, as a valid hash might simply lack the specific first field requested. This can cause spurious regressions (like accidentally deleting valid sessions).
**Action:** Always parse the slice of interfaces returned by `HMGet` using safe two-value type assertions (e.g., `if str, ok := vals[0].(string); ok`), and verify existence by checking if any fields were successfully parsed (e.g., `len(data) > 0`) instead of relying on a single field's presence.
